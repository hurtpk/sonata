======================================================================
                        HOW TO INSTALL SONATA
======================================================================

Sonata adds about a hundred features to Discord, all in one page.
It's a plugin for Equicord, a Discord mod, so this installs both.

Heads-up: client mods like Equicord are against Discord's Terms of
Service. People rarely get in trouble for using one, but it's your call.


----------------------------------------------------------------------
 THE EASY WAY  (about 5-10 minutes)
----------------------------------------------------------------------

1. Download the installer - it's the only file you need:

     https://github.com/hurtpk/sonata/raw/main/Install%20Sonata.bat

   (Or open https://github.com/hurtpk/sonata, click "Install Sonata.bat",
   then the download button.)

2. Double-click "Install Sonata.bat".

   If Windows says "Windows protected your PC", click "More info",
   then "Run anyway" - Windows says this about any downloaded .bat file.

   It installs anything that's missing (Git, Node.js, pnpm), downloads
   Equicord into your Documents folder (or your user folder, if
   Documents is synced by OneDrive), downloads Sonata, and builds it.
   If you already have Equicord, it uses that one.
   (Got a "sonata" folder from a friend instead? Put the installer
   inside it and it uses that copy.)
   When it asks which Discord to install into, pick yours (usually
   "Stable") and press Enter.

   If Windows asks "Do you want to allow this app to make changes?"
   while it's installing Git or Node.js, click Yes.

   If it says "Windows needs a fresh window", just close it and
   double-click "Install Sonata.bat" again - it carries on.

3. FULLY close Discord: right-click the Discord icon by the clock
   (bottom-right of the screen) and choose "Quit Discord".
   Then open Discord again.

4. Open Sonata with the music-note button under your profile picture.
   A short welcome tour helps you pick your features.


----------------------------------------------------------------------
 THE MANUAL WAY  (if the .bat doesn't work for you)
----------------------------------------------------------------------

1. Install these free programs (keep the default options):

     Git        https://git-scm.com/download/win
     Node.js    https://nodejs.org      (the "LTS" version, 22 or newer)

2. Open PowerShell (press Start, type PowerShell, press Enter) and run
   these one at a time:

     npm install -g pnpm
     cd ~\Documents
     git clone https://github.com/Equicord/Equicord
     cd Equicord
     pnpm install

3. Still in PowerShell, download Sonata into Equicord's plugin folder:

     git clone https://github.com/hurtpk/sonata src\userplugins\sonata

   (Or download it from https://github.com/hurtpk/sonata -> Code ->
   Download ZIP, unzip it, and put the folder in
   Documents\Equicord\src\userplugins\ named "sonata".)

   Either way, this file should exist:

     Documents\Equicord\src\userplugins\sonata\index.tsx

4. Back in PowerShell (still in the Equicord folder), run:

     pnpm build
     pnpm inject

   Pick your Discord (usually "Stable") when it asks.

5. Fully close Discord (tray icon -> Quit Discord) and open it again.


----------------------------------------------------------------------
 OPTIONAL: MEDIA DOWNLOADER
----------------------------------------------------------------------

Sonata's Media Downloader saves videos and music from YouTube,
SoundCloud, TikTok, Instagram, X, Reddit and more. It needs a free
program called yt-dlp. The installer offers it; or run this in
PowerShell:

     winget install yt-dlp

Then fully close and reopen Discord.


----------------------------------------------------------------------
 UPDATING SONATA
----------------------------------------------------------------------

Double-click "Install Sonata.bat" again. It downloads the newest Sonata
from GitHub and rebuilds. Then press Ctrl+R in Discord (or restart it).

By hand: in PowerShell, in the Equicord folder, run

     git -C src\userplugins\sonata pull
     pnpm build

then press Ctrl+R in Discord.


----------------------------------------------------------------------
 UNINSTALLING
----------------------------------------------------------------------

In PowerShell:

     cd ~\Documents\Equicord
     pnpm uninject

Then fully close and reopen Discord.


----------------------------------------------------------------------
 SOMETHING WRONG?
----------------------------------------------------------------------

 "pnpm is not recognised"
     Close PowerShell and open it again after installing Node.js
     and pnpm.

 Discord opens without Equicord or Sonata
     Discord updates sometimes remove it. Run "pnpm inject" again in
     the Equicord folder (or double-click the installer again).

 A feature stopped working after a Discord update
     Open Sonata Insights inside Sonata - it shows what broke and how
     to fix it.

 Discord feels slow
     In Sonata, open the Performance tab and pick "Light".
